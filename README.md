# Lecture Lab AI

An AI-powered activity generator that turns lecture documents into interactive learning activities. 
Built with Lovable AI, Supabase, and Gemini API.

## Features
- Upload PDF, PPTX, DOCX, TXT
- 14 activity modes including SQL MCQ
- No login required
- Instant feedback with explanations

## Live Demo
https://docu-activity-bot.lovable.app

## Tech Stack
- Lovable AI (frontend + backend)
- Supabase (database + storage)
- Gemini API (AI generation)

## How to Use
1. Upload a document
2. AI extracts topics
3. Select a topic
4. Choose an activity mode
5. Answer and learn
